1. 机场是什么 (基础概念)

新手最常问的入门概念，搞懂机场、梯子与科学上网的关系。
机场是什么？
简单说，机场就是卖代理节点订阅的服务商。您付费购买套餐后，拿到一条专属的“订阅链接”，导入 Clash、Shadowrocket 或 v2rayN 等客户端就能使用。因早期 V2Ray 客户端图标是纸飞机，业内便习惯将此类加速服务称为“机场”。
机场和传统 VPN 有什么区别？
传统 VPN 通常由单一公司提供捆绑客户端与固定线路；而机场卖的是标准的“订阅链接”，您可以自由选择最顺手的客户端（如 Clash Verge Rev、小火箭），自己按需切换不同地区或低延迟节点，玩法更灵活且速度上限极高。
机场和“梯子”是一回事吗？
“梯子”是所有跨境翻墙加速工具的民间统称，而“机场”是目前用户量最大、性价比最高的一种落地服务形式。
自建节点和买机场哪个更好？
自建节点需要自己购买海外 VPS、配置安全协议并承担 IP 被封锁的维护风险；而购买商业机场省心很多，由专业团队维护物理 IEPL/IPLC 专线与出口 IP 轮换，对绝大多数日常用户而言，买专线机场性价比更高。

2. 新手怎么选机场

第一次挑选机场的核心考量维度与避坑建议。
新手挑选机场应该看哪些核心因素？
重点关注 4 点：**晚高峰稳定度**（是否为物理 IEPL/IPLC 专线）、**原生 IP 解锁能力**（ChatGPT 4o 与 Netflix 是否免验证）、**月付或活动套餐的门槛**以及**专享 7 折优惠码**（如 `HQ66`、`dly88`）。
机场购买前最需要注意什么？
坚决不要在第一次使用时购买长期大包（如 5 年包），必须先选择月付或活动特惠套餐，亲自验证本地运营商在晚高峰 21:00 的真实速度与丢包情况。

3. 机场订阅链接怎么导入

主流客户端一键导入配置图文流程。
机场订阅链接怎么导入 Clash / Clash Verge？
复制机场后台的 Clash 订阅链接，打开 Clash Verge 点击【Profiles (配置)】，在顶部 URL 框中粘贴链接并点击 Import (导入)，更新成功后右键选择配置并开启 TUN 模式或系统代理。
机场订阅链接怎么导入 Shadowrocket (小火箭)？
打开 Shadowrocket，点击右上角【+】，类型选择【Subscribe】，在 URL 一栏粘贴机场订阅地址并保存，随后在主界面下拉刷新即可自动下载全部节点。
机场订阅链接怎么导入 v2rayN？
打开 v2rayN 顶部菜单【订阅分组】->【订阅分组设置】，添加一条新分组并在【可选地址】中粘贴订阅链接保存，随后点击【订阅分组】->【更新订阅】即可。

5. 机场节点怎么选

香港、日本、美国与新加坡节点特性拆解。
港日美新节点各自有什么特点？
**香港节点**延迟最低（20ms 左右），适合日常网页与游戏；**日本节点**走沪日专线，适合动漫与日服游戏；**美国节点**广播原生 IP，是解锁 ChatGPT 与 OpenAI 接口的首选；**新加坡节点**适合东南亚流媒体解锁。
什么是流量倍率？
倍率代表流量扣除比例：1.0x 倍率消耗 1GB 扣除 1GB 额度；高倍率（如 3.0x）消耗 1GB 扣除 3GB 额度。选购时认准 1.0x 标准倍率专线节点。

6. 机场卡顿连不上怎么办 (故障排查)

针对节点 Timeout、订阅更新 403 报错的快速自查步骤。
节点全部显示 -1ms 或 Timeout 报错怎么办？
1) 检查系统时间是否精准同步；2) 重新刷新更新订阅；3) 检查本地防火墙或安全软件是否阻断；4) 尝试切换节点模式为 Rule 规则分流。

7. 流量和套餐怎么选

结合预算与使用量挑选最省钱的规格。
一般用户每月需要多少流量？
