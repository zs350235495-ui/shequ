社区维护了主流客户端的精简分流规则，兼顾国内访问速度与海外隐私防泄漏：

1. **Clash / Mihomo (Clash Meta)**：推荐配合 GEOIP/GEOSITE 规则集，国内流量直连，远程解析 DNS 开启 Fake-IP。
2. **Sing-box**：支持原生 Hysteria 2 / TUIC / VLESS-Reality，采用轻量内存占用架构。
3. **Surge (iOS / macOS)**：建议启用网络诊断面板，实时监控单节点 TCP 握手 RTT。
4. **Shadowrocket (小火箭)**：建议关闭全局直连中的 IPv6 漏油选项，开启 DNS 预解析。
