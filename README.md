## 🔬 分布式节点健康度评估与遥测算法 (Telemetry & SLA)

社区探针采用轻量级无状态探测脚本，针对多节点集群实施 7x24 小时高频采样，计算模型如下：

### 1. 服务等级协议 (SLA) 可用率量化公式
$$SLA = \frac{T_{Total} - T_{Outage}}{T_{Total}} \times 100\%$$
* $T_{Total}$ 为全月连续监控总时长（如 43,200 分钟）。
* $T_{Outage}$ 为连续探测失败（单次握手超时超 3,000ms 且持续 3 次以上）的故障停机累计时长。

### 2. 平均修复时间 (MTTR) 与平均无故障时间 (MTBF)
* **平均修复时间 (Mean Time to Repair, MTTR)**：
  $$MTTR = \frac{\sum T_{Down}}{N_{Failures}}$$
  量化服务商在骨干网抖动或节点封锁发生后，主备路由自动漂移与恢复联通的平均耗时。
* **平均无故障时间 (Mean Time Between Failures, MTBF)**：衡量长周期稳定运行能力，IEPL 专线集群基准要求 MTBF ≥ 720 小时。
